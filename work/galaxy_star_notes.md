# NOSTRAVECTOR: Milky Way chart

The catalogue contains Sol, Janira Proxima and 88 other systems (90 total). The original ten generated systems keep their identifiers, planets, terrain and navigation coordinates. The 78 additions include seven named stars and 71 fictional systems. Added systems begin neutral; the existing Sol and Janira story relationships remain intact.

This is a schematic Milky Way game chart. Coordinates and 72 LY routes are compressed gameplay distances, not measured astronomical positions. The planets, economies and settlements surrounding the named real stars are fictional. Alpha Centauri represents A/B; its distant companion Proxima has a separate playable destination.

Confirmed stellar categories used for named stars:

- [NASA: Betelgeuse, red supergiant](https://science.nasa.gov/universe/what-is-betelgeuse-inside-the-strange-volatile-star/)
- [NASA: Alpha Centauri and red dwarf companion Proxima](https://www.nasa.gov/image-article/alpha-centauri-triple-star-system-about-4-light-years-from-earth/)
- [NASA: VY Canis Majoris, red hypergiant](https://science.nasa.gov/missions/hubble/hubble-solves-mystery-of-monster-stars-dimming/)
- [ESO research: UY Scuti, red supergiant](https://www.eso.org/~mwittkow/publications/refereed/Arroyoetal2013.pdf)
- [NASA: Rigel, blue supergiant](https://science.nasa.gov/image-article/apod-1998-august-29-orion-star-colours/)
- [NASA stellar classification table: Arcturus K1.5III, Rigel B8Iab, Betelgeuse M2Iab](https://pumas.nasa.gov/sites/default/files/examples/03_05_10_2.pdf)

Use the searchable directory to select any system. Nearby cards list up to five reachable systems. Selecting a distant system shows a multi-jump route; each jump still requires an explicit command and one Warp Cell. Scanning, crafting and manual saves follow existing rules. Generated planet textures load as systems are visited.

## Evolved star systems

Red supergiant stellar radii now span approximately 1,820–2,170 game units, compared with Sol's 62. Hypergiants have radius 7,200. These are exaggerated game presentation sizes. Every supergiant has only one or two scorched volcanic planets, placed beyond the expanded star. Hypergiants have zero planets or stations. Their stellar anchors are navigation references, never landable worlds or scan results. Old saves on removed worlds relocate to safe space in the same system while retaining inventory, fuel and story progress. Manual saves remain required.
